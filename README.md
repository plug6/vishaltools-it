## About

The **Vishal Tools IT Team** builds and maintains the software systems, infrastructure, and integrations that keep Vishal Tools running — from shop floor to boardroom. Our work spans enterprise applications, SAP ecosystems, business intelligence, and internal tooling.

---

## Core Areas

| Area | Scope |
|---|---|
| **Enterprise Applications** | Internal platforms, ERP modules, and business-critical software |
| **SAP Integration** | SAP HANA connectivity, data pipelines, and process bridges |
| **Business Intelligence & Reporting** | Dashboards, analytics, and operational reporting |
| **IT Infrastructure** | Servers, networking, deployment, and uptime |
| **Process Automation** | Workflow automation and internal tooling |
| **Information Security** | Access control, audits, and security policies |
| **Technical Support** | Internal helpdesk and systems support |
